# Pratibodh Solanki — AI/ML Portfolio

A minimal, research-focused personal website built with React, TypeScript, and Vite.

## Updating content

All personal content lives in `src/data/portfolio.ts`. Add publications, projects, experience, education, skills, and document links there. Empty sections stay hidden automatically.

## Local development

```bash
npm install
npm run dev
```

## Deployment

Every push to `main` is deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.
